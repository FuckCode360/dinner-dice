# PROJECT.md

## 项目概述

Dinner Dice 是一个个人使用的“今天吃什么”轮盘工具。它把常吃店、外卖收藏和想吃的菜手动整理成本地饭库，再根据预算、距离、健康程度和辣度偏好随机给出一个选择。

第一版目标是减少日常吃饭选择成本，而不是做大众点评、外卖平台同步器或营养分析系统。

## 当前目标

实现一个手机优先、无后端、可本地运行的 MVP：

- 手动录入常吃店或菜品。
- 设置预算、距离、健康程度、辣度和堂食/外卖偏好。
- 按条件摇出一个结果。
- 记录最近吃过，降低短期重复概率。
- 支持本地数据导入和导出。
- 支持三种抽卡页面视觉：食运占卜、粉色扭蛋、星际召唤。

## 技术栈

- Node.js + npm。
- Vite + React + TypeScript。
- 普通 CSS。
- `lucide-react` 图标。
- 浏览器 `localStorage` 保存个人饭库和历史记录。

## 代码结构

- `src/App.tsx`：主应用、视图切换、表单和页面状态。
- `src/storage.ts`：本地数据读写、导入导出所需的数据结构检查。
- `src/dice.ts`：筛选和加权随机逻辑。
- `src/types.ts`：饭库、历史、筛选条件等类型定义。
- `src/styles.css`：手机优先界面样式。
- `src/assets/`：项目内生成图片资源，目前包含三套抽卡背景。
- `docs/`：项目说明、进度、开发使用说明和阶段计划。

## 关键约束

- 第一版只做个人本地工具，不做账号系统和云端同步。
- 第一版不自动读取美团、饿了么或其他外卖平台收藏。
- 所有健康、辣度、距离和预算信息由用户主观填写。
- 浏览器本地数据可能被清理，所以必须提供导出/导入 JSON 备份能力。

## 非目标

- 不做外卖平台登录、收藏同步、网页抓取或绕过平台限制。
- 不做实时地图距离、配送费、商家营业状态或价格变动。
- 不做多人共享、协作饭局或推荐社区。
- 不做复杂营养计算和医学健康建议。
